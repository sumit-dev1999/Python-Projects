# Project 01: Simple Calculator

**Author:** Sumit Laxman Atloori

## Description
A simple calculator developed using Python to perform basic mathematical operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division

## Technologies
- Python
- Jupyter Notebook
- Visual Studio Code (VS Code)

## Python Concepts Used
- Variables
- Data Types
- User Input (input())
- Type Conversion (float())
- Arithmetic Operators
- Conditional Statements (if, elif, else)
- Nested Conditional Statements

## How to Run
- Clone or download this repository.
- Open the project folder in Visual Studio Code or Jupyter Notebook.
- Open 01_Simple_Calculator.ipynb.
- Execute the notebook cells in sequence.
- Enter the first number and second number.
- Enter an arithmetic operator (+, -, *, /).
- View the calculated result.
