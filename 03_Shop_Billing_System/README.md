## 3. Project Overview

The Shop Billing System is a beginner-friendly Python project designed to generate customer invoices by accepting product information from the user.
The program takes product name, product price, quantity, and GST percentage as input.
It automatically calculates the total amount, GST amount, and final bill using Python arithmetic operations.
This project demonstrates how Python can be used to solve basic real-world business problems, such as shop billing and invoice calculations.

## 4. Features

- Accept product name from the user.
- Accept product price from the user.
- Accept product quantity.
- Accept GST percentage.
- Calculate total product amount.
- Calculate GST amount.
- Calculate the final payable amount.
- Display a formatted shop invoice.
- Display Indian Rupee symbol using Unicode (`\u20b9`).
- Format currency values using commas and decimal places.
