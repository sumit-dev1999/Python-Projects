## 3. Project Overview

The Employee Management System is a beginner-friendly Python console application designed to manage basic employee records.

This project allows users to add new employees, view all employee records, search employees using their Employee ID, and calculate annual salaries based on monthly salaries.

The project was developed to practice Python fundamentals and understand how employee information can be stored, managed, searched, and displayed using programming logic.

## 4. Features

- Add new employee records
- View all employees
- Search employees by Employee ID
- Prevent duplicate Employee IDs
- Store employee details
- Calculate annual salary automatically
- Interactive menu-driven system
- User-friendly console interface
- Exit the application

## 5. Employee Information

The system maintains the following employee details:

| Field | Description |
|---|---|
| Employee ID | Unique identification number |
| Employee Name | Full name of employee |
| Department | Employee department |
| Designation | Job title or role |
| Monthly Salary | Monthly employee salary |
| Annual Salary | Monthly salary multiplied by 12 |

## 8. How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code or Jupyter Notebook.
3. Open `employee_management_system.py`.
4. Run the Python file.
5. Select an option from the menu.
6. Enter the employee details as required.

## 9. Project Limitations

- Employee records are stored temporarily in a Python list.
- Data is lost when the program is closed.
- Employees cannot be updated or deleted.
- Salary calculation only includes basic annual salary.
- No database is connected.
- The application uses a console-based interface.
