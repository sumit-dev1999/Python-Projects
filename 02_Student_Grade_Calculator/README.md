## 3. Project Overview

The Student Grade Calculator is a Python-based project designed to calculate the academic performance of a 10th Standard student across six subjects.

The program accepts the student's name and marks in English, Mathematics, Science, Computer, Hindi, and Marathi.

It calculates:

- Total Marks
- Percentage
- Average Marks
- Final Grade
- Pass or Fail Result

The main purpose of this project is to understand Python programming fundamentals and learn how to solve real-world calculation problems using Python.

## 5. Grade Conditions

The project uses percentage-based grading conditions.

| Percentage | Grade |
|---|---|
| 90% and above | A+ |
| 80% to below 90% | A |
| 70% to below 80% | B |
| 60% to below 70% | C |
| 50% to below 60% | D |
| 35% to below 50% | E |
| Below 35% | F |

### Pass or Fail Conditions

- A student must score at least 35 marks in every subject to pass.
- If a student scores below 35 marks in any one subject, the final result will be FAIL.
- If the student fails in any subject, the final grade will be F, regardless of the overall percentage.

**Note:** These are the grading rules defined for this practice project, not necessarily the official grading rules of a particular school or board.
